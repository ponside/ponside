# Ponside — Coming Soon

A production-ready, single-page teaser built with Next.js, TypeScript, Tailwind CSS, and the App Router.

## Edit brand settings

Update all external branding values in `lib/config.ts`:

- `PROJECT_NAME`
- `SITE_URL`
- `X_URL`
- `OG_IMAGE`

## Run locally

```bash
npm install
npm run dev
```

## Verify production readiness

```bash
npm run lint
npm run typecheck
npm run build
```

The project uses standard Next.js conventions and can be imported directly into Vercel.
